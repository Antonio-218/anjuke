# 安居客南京首页克隆

这是一个用于学习与考核的静态页面克隆作品，入口文件为 `index.html`。

## 本地预览

直接双击 `index.html`，或使用 VS Code Live Server 打开。

## 发布建议

可使用 Wix Studio、Netlify、Vercel 或 GitHub Pages 发布。若使用 Wix Studio，可按以下方式迁移：

1. 新建 Wix Studio 项目，选择空白响应式页面。
2. 按 `index.html` 的模块结构搭建：顶部栏、导航首屏、搜索框、快捷入口、新房、二手房、租房、页脚。
3. 按 `styles.css` 中的颜色、间距、圆角、阴影与响应式布局设置样式。
4. 替换为合法可使用的图片素材后发布。

> 注意：本项目不是安居客官方网站，仅用于页面仿写练习。
